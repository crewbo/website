# Contributing

The website follows the main Crewbo project's process: read [Crewbo's CONTRIBUTING.md](https://github.com/crewbo/crewbo/blob/main/CONTRIBUTING.md) and its [code of conduct](https://github.com/crewbo/crewbo/blob/main/CODE_OF_CONDUCT.md).

- **CLA:** before your first pull request can be merged, sign the [Crewbo Contributor License Agreement](https://github.com/crewbo/crewbo/blob/main/docs/legal/CLA.md) once; the CLA assistant bot comments on the pull request with a link.
- **Licence:** contributions to this repository are licensed under its [Apache License 2.0](LICENSE).
- **Workflow:** branch from `main` as `<type>/<short-kebab-description>`, one pull request per change (issues live in [crewbo/crewbo](https://github.com/crewbo/crewbo/issues)), [Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0/).
- **Writing:** follow Crewbo's [voice](https://github.com/crewbo/crewbo/blob/main/docs/brand/08-voice.md): plain English, sentence case, no em dashes, no exclamation marks, no emoji.
