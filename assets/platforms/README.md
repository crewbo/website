The logos of the editor and operating systems Crewbo runs on, as their owners or public icon sets ship them. They belong to their owners; Crewbo is not affiliated with them.

Ronel decided on 2026-10-25 to show these logos and to ask the owners before launch, as with the agent logos. Their written terms say no without a licence, so expect to remove them:

- VS Code (https://code.visualstudio.com/brand): "Using the icon to identify or promote your own product, service, application, VS Code extension" is not OK.
- Microsoft (https://www.microsoft.com/en-us/legal/intellectualproperty/trademarks): "Don't use Microsoft's logos, icons, or designs, in any manner."
- Apple (https://www.apple.com/legal/intellectual-property/guidelinesfor3rdparties.html): "You may not use the Apple Logo ... except pursuant to an express written trademark license from Apple."

All three allow the product's name to say that Crewbo works with it, so the fallback is the names without logos.
