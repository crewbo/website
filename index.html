05 · Questions

Does Crewbo see my code?

No. File contents never leave your computer; only paths, task text, branch names, the agent's name and who is online go to your team's own server.

Do I need the Crewbo IDE?

No. The extension and the crewbo command work on their own; the IDE is a preview with everything in one download.

What is the sync server?

A small server one teammate runs with crewbo serve. It passes claims and presence between teammates.

Is it open source?

Yes: Apache-2.0, with the sync server under AGPL-3.0.
